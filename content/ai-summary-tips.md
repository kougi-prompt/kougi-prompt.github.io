講義資料のPDFをAIに渡して「要約して」と頼むと、それらしい要約はすぐに返ってきます。ただ、そのまま復習に使おうとすると、次のような困りごとが起きがちです。

- 講義で強調されていた点が抜けて、教科書的な一般論になっている
- 資料に書かれていないことが、資料の内容のように混ざっている
- 要約を読んだだけで、わかった気になってしまう

ここでは、復習に使える要約を作るための5つのコツを紹介します。

## 1. 講義の前提を伝える

AIは、あなたがどんな講義を受けていて、どこでつまずいているのかを知りません。前提を伝えるだけで、要約で重視される点が大きく変わります。

伝えるとよいのは、次のような情報です。

- 講義名と分野（例：ミクロ経済学、経済学）
- 講義の形式（例：スライド中心、板書中心）
- 評価方法（例：期末試験とレポート）
- 自分の理解度や苦手なところ（例：グラフの読み取りが苦手）

たとえば「スライド中心」と伝えると、箇条書きで断片的になりがちなスライドについて、スライド同士のつながりを補った要約を頼めます。

## 2. 出力の形を決めておく

「要約して」だけだと、長さも形もAI任せになります。復習しやすい形を最初に指定しましょう。

```
# 出力形式
1. 3行まとめ：この回の内容をひとことで
2. 要点：見出しごとに箇条書き
3. 重要用語：用語と短い説明（表形式）
4. 理解度チェック：理解を確かめる問題を3問（解答は最後にまとめる）
5. 疑問点：資料だけではわかりにくい点
```

形が決まっていると、毎回の講義の要約を同じ形でそろえられるので、試験前に見返すときも楽になります。

## 3. 資料にないことは「補足」と書かせる

AIは、資料にない内容を自然に補ってしまうことがあります。補足そのものは役に立つこともありますが、資料の内容と区別できないと困ります。

プロンプトに次の一文を入れておくと、見分けやすくなります。

```
資料にない内容を補う場合は「（補足）」と明記し、資料の内容と区別してください。
```

それでも、数値や固有名詞、数式などをAIが読み違えることはあります。試験に関わる大事なところは、元の資料で確かめる習慣をつけましょう。

## 4. 資料の渡し方を工夫する

- **ファイルを添付する**：PDFやスライドを添付できるAIなら、それがいちばん手軽です。
- **長い資料は分ける**：1回分の資料が長いときは、前半と後半、章ごとなどに分けて渡すと、抜けが少なくなります。
- **写真やスキャンに注意する**：写真やスキャンしたPDFは、文字をうまく読み取れないことがあります。読み取れない部分は推測で埋めずに「判読不能」と書くよう頼んでおくと安心です。

ファイルの添付や、一度に読み込める量は、AIサービスや料金プランによって違います。

## 5. 要約を読んで終わりにしない

要約は、読むだけだとすぐに忘れてしまいます。要約と一緒に「理解度チェック」の問題を出してもらい、答えを見ずに解いてみましょう。思い出そうとすること自体が、記憶の定着に役立ちます。

わからなかったところは、そのまま「わからない所の解説」で質問すると、つまずきを早めに解消できます。

## プロンプトの例

ここまでのコツを入れると、プロンプトはたとえば次のようになります。

```
あなたは経済学・経営学を専門とする大学教員で、学生の復習に役立つ要約を作るのが得意です。
以下の前提をふまえて、依頼に答えてください。

# 前提
- 講義名：ミクロ経済学Ⅰ
- 講義の形式：スライド中心
- 評価方法：期末試験・レポート
- いまの理解度：あまりついていけていない

# 依頼
講義資料の内容を、復習に使えるように要約してください。

# 条件
- スライド同士のつながりを補ってください。
- 専門用語にはかみ砕いた説明を添えてください。
- 資料にない内容を補う場合は「（補足）」と明記してください。
- 試験に出そうな重要ポイントには ★ を付けてください。
```

[講義プロンプトメーカー](./)で講義の情報を入れて「講義資料の要約」を選ぶと、このようなプロンプトが自動でできあがります。
